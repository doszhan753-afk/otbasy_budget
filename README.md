# Отбасы бюджеті

Үй шаруашылығының (отбасының) кірісі мен шығысын есепке алу веб-бағдарламасы.
Курстық жұмыс тақырыбы: **«Үй шаруаларын есепке алу бағдарламасын әзірлеу»**.

**Технологиялар:** Python 3, Flask, SQLite, HTML/CSS/JavaScript (сыртқы кітапханасыз, интернетсіз жұмыс істейді).

## Мүмкіндіктер

| Бөлім | Не істейді |
|---|---|
| Тіркелу / кіру | Әр отбасы өз аккаунтымен кіреді, құпиясөз хэшпен сақталады, деректер басқа пайдаланушыларға көрінбейді |
| Шолу | Айдың кірісі, шығысы, қалдығы; шығыс құрылымының дөңгелек диаграммасы; соңғы 6 айдың динамикасы; лимиттердің орындалуы |
| Операциялар | Кіріс/шығыс қосу, өңдеу, жою; ай, түрі, санаты, мүшесі және түсініктеме бойынша сүзу мен іздеу; беттеу |
| Санаттар | Өз санаттарыңызды қосу/жою (тіркелгенде 14 бастапқы санат қосылады) |
| Отбасы мүшелері | Әр операцияны кім жасағанын белгілеу, мүше бойынша жиынтық |
| Лимиттер | Санат бойынша айлық шек, орындалу көрсеткіші (80%-дан ескерту, асқанда қызыл), өткен айдан көшіру |
| Есептер | Айлық есеп: санаттар бойынша үлес, мүшелер бойынша, ең үлкен 5 шығыс, күніне орта шығыс, жинақтау үлесі; **CSV (Excel)** экспорты; басып шығару |

Интерфейс толығымен қазақ тілінде, телефонда да ыңғайлы (адаптивті).

## Іске қосу

```bash
python -m venv venv
venv\Scripts\activate          # Windows
# source venv/bin/activate     # Linux / macOS
pip install -r requirements.txt

python app.py
```

Браузерде ашыңыз: <http://127.0.0.1:5000>

Дерекқор (`budget.db`) бірінші іске қосуда автоматты түрде жасалады.

### Демо-деректермен көру (қорғау алдында ыңғайлы)

```bash
python seed_demo.py
```

Кіру: логин `demo`, құпиясөз `demo1234`. 6 айлық шынайы деректер мен лимиттер жасалады.

### Тесттер

```bash
python -m pytest -q
```

24 автоматты тест: тіркелу/кіру, CSRF, операциялар CRUD, валидация, пайдаланушылар оқшаулануы, лимиттер, есеп сомалары, CSV экспорты.

## Дерекқор схемасы

```
users(id, username UNIQUE, password_hash, family_name, created_at)
members(id, user_id → users, name)                       UNIQUE(user_id, name)
categories(id, user_id → users, name, kind[income|expense])   UNIQUE(user_id, name, kind)
transactions(id, user_id → users, category_id → categories, member_id → members NULL,
             kind, amount > 0, tx_date, note, created_at)
budgets(id, user_id → users, category_id → categories, month 'YYYY-MM', limit_amount > 0)
                                                         UNIQUE(category_id, month)
```

Байланыстар: пайдаланушы өшірілсе, оның барлық деректері өшеді (`CASCADE`); операциясы бар санатты өшіруге болмайды (`RESTRICT`); мүше өшірілсе, операциялары сақталады (`SET NULL`).

## Қауіпсіздік

- Құпиясөздер `werkzeug.security` арқылы хэштеледі (ашық түрде сақталмайды).
- Барлық POST сұраулары CSRF-токенмен қорғалған.
- SQL сұраулары параметрлендірілген (SQL-инъекциядан қорғау), Jinja2 автоэкрандау (XSS-тен қорғау).
- Әр сұраудағы дерек `user_id` бойынша сүзіледі, басқа отбасының деректеріне қол жеткізу мүмкін емес.
- CSP, `X-Frame-Options`, `X-Content-Type-Options` тақырыптары; cookie `HttpOnly` + `SameSite=Lax`.
- CSV экспортында Excel формула-инъекциясынан қорғау.
- Құпия кілт `SECRET_KEY` ортасынан не бірінші іске қосуда жасалатын `.secret_key` файлынан алынады.

## Шектеулер және даму жолдары

- Сома бүтін теңгемен сақталады (тиынсыз).
- Бір аккаунт = бір отбасы; бірнеше пайдаланушыны бір отбасыға қосу әзірге жоқ.
- Кіру әрекеттерін шектеу (brute-force қорғанысы) және құпиясөзді қалпына келтіру қосылмаған.
- Болашақта: қайталанатын төлемдер, чек суретін тіркеу, мобильді қосымша, PDF-есеп.
